# Hammad Shaukat — Portfolio

Senior .NET & full-stack developer portfolio built with React, TypeScript, and Vite.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Customize

Edit personal details, experience, projects, and skills in [`src/data/content.ts`](src/data/content.ts).
